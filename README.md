# CAC Game Project 2026

A game I'm developing for the **Congressional App Challenge 2026**.

## About
This is an game built entirely in c++ that has you against a AI that will learn after your actions to get better and better at fighting against you. the core loop will include you fighting the AI until on of you dies, there will be cover and arrows that spawn around the map to allow you to get a temporary ranged attack. after each round you will be able to level up your stats and unlock some new abilities to allow you to face against the AI better.

## Features
- Player controller
- Combat system
- Particle effects
- AI enemy
- Collision detection
- Custom UI rendering
